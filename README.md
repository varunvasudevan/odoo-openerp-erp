# 🧾 Odoo / OpenERP – ERP Implementation & Administration

ERP work at **Tadpole Engineering, Chennai**, where I was IT Manager. I customised OpenERP for the business and later ran the company's Odoo server.

> ℹ️ This is a showcase repository describing my experience. The client's ERP code, data and configuration are private.

---

## 🛠️ What I did

| Area | Work |
|---|---|
| **Implementation & setup** | Installed and configured the ERP, set up modules for the company's processes, and migrated data |
| **Customisation & development** | Customised OpenERP: custom modules, forms, views and reports built to the business's requirements |
| **Server administration & upgrades** | Managed the Odoo server on Linux, including the PostgreSQL database, backups and version upgrades |
| **User training & support** | Trained staff and gave day-to-day support to ERP users |

## 🧩 Versions

- **OpenERP 6 / 7**: customisation and development
- **Odoo 13+**: server management, upgrades and administration
